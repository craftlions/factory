craftlions Factory

Signed APT repository for the Factory appliance. Install once, then receive updates through APT.

Target: Debian with systemd · amd64 · stable

1. Add the repository

Run these commands on your device. You will need curl and administrator access.

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL \
  https://craftlions.github.io/factory/craftlions-factory-archive-keyring.asc \
  -o /etc/apt/keyrings/craftlions-factory-archive-keyring.asc
sudo chmod 0644 /etc/apt/keyrings/craftlions-factory-archive-keyring.asc

sudo tee /etc/apt/sources.list.d/craftlions-factory.sources >/dev/null <<'EOF'
Types: deb
URIs: https://craftlions.github.io/factory/
Suites: stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/craftlions-factory-archive-keyring.asc
EOF

2. Install Factory

sudo apt update
sudo apt install craftlions-factory

Open http://DEVICE_IP/ (port 80) in your browser, replacing DEVICE_IP with your device’s IP address.

3. Update Factory

sudo apt update
sudo apt install --only-upgrade craftlions-factory

The Factory service restarts automatically after an upgrade.
